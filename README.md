# Shiftly - Multi-Platform Shift Tracker

Shiftly היא פלטפורמה לניהול ומעקב משמרות עבודה, המיועדת לספק מענה מדויק לחישוב שכר נטו, ניהול הפסקות
ורישום טיפים. האפליקציה נבנתה ב-Flutter ותומכת ב-Android, iOS, Windows, macOS, Linux ו-Web.

## תכונות עיקריות

* **מעקב זמן אמת:** שעון עצר (Timer) מובנה לניהול משמרת פעילה, כולל אפשרות למעבר למצב הפסקה וחזרה
  לעבודה בלחיצה אחת.
* **חישוב שכר ברמת דיוק גבוהה:** המערכת מחשבת שעות עבודה נטו על בסיס שניות (דיוק של 2 ספרות
  עשרוניות) כדי להבטיח חישוב שכר מדויק.
* **מנוע פיענוח טקסט (Smart Parser):** אפשרות להזנת משמרות מרובות באמצעות הדבקת טקסט חופשי (לדוגמה
  מהודעות WhatsApp). המערכת מזהה אוטומטית תאריכים, טווח שעות, סוגי הפסקה וטיפים.
* **ניהול הפסקות מוגדר מראש:** תמיכה בהפסקות בתשלום (מנוכות מהזמן אך לא מהשכר) והפסקות ללא תשלום (
  מנוכות מהסך הכולל), עם אפשרות להגדרת ברירת מחדל ב-Onboarding.
* **לוח שנה אינטראקטיבי:** תצוגה חודשית לניהול היסטוריית המשמרות, כולל אפשרות לעריכה מהירה ומחיקה
  בהחלקה (Swipe).
* **פרטיות מקומית:** שימוש בבסיס נתונים NoSQL מקומי (Hive) המבטיח שהמידע נשמר על המכשיר בלבד ואינו
  נשלח לשרת חיצוני.

## מפרט טכני

* **UI Framework:** Flutter (Material 3 Design).
* **State Management:** Provider.
* **Persistence:** Hive (Local Storage).
* **Localization:** תמיכה מלאה בעברית ובתצוגת מימין לשמאל (RTL).
* **Build Pipeline:** GitHub Actions לפרסום אוטומטית של Artifacts ל-6 פלטפורמות.

## פורמט הזנה (Smart Paste)

המערכת תומכת בפורמט הבא:
`[DD.MM.YYYY] - [HH:mm] - [HH:mm] [Break Type] + [Tips]`

**דוגמאות מזוהות:**

* `06.09.2026 - 09:00 - 17:00 45 דקות + 50`
* `06.09 - 22:00 - 06:00 ללא` (תמיכה במשמרות לילה)

## התקנה ופיתוח מקומי

1. **התקנת תלויות:**
   ```bash
   flutter pub get
   ```
2. **יצירת קבצי Adapters (Hive):**
   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```
3. **הרצה:**
   ```bash
   flutter run
   ```

## בנייה להפצה (Android)

כדי לייצר קבצי התקנה אופטימליים (משקל נמוך בפורמט Release), מומלץ להשתמש בפיצול לפי ארכיטקטורת מעבד:

```bash
flutter build apk --release --split-per-abi
```

## בדיקות (Testing)

הרצת בדיקות יחידה ללוגיקת חישוב השעות והפיענוח:

```bash
flutter test test/unit/shift_logic_test.dart
```
